Zero touch

The extension lives in template1. Every new database gets a schema, a default schedule (daily at 02:00, keep 14 backups, max 90 days) and a first backup within a minute.

Restore into a new name

Restore one database into a new name with SQL. Server gone? pgbx db-restore --from-s3 restores straight from S3 onto a fresh server, no extension needed.

Works when Postgres is down

pgbx is a standalone CLI. It restores from S3 directly, diagnoses why Postgres will not start, and speaks --json for scripts and AI agents.
