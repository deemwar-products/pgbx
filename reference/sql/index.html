SQL functions

Per-database functions run inside the database they manage. overview() and doctor() run only in the admin database (pgbx.admin_db, default postgres). Jobs are rows in pgbx.history (queued → running → done | failed | expired).

Status (viewer)

Section titled “Status (viewer)”

status()

Section titled “status()”

Who: pgbx_viewer. One row: “are we backed up?”

backups (view)

Section titled “backups (view)”

Columns: id, taken_at, age, trigger, size, bytes, s3_key. Every kept backup, newest first. Who: viewer.

history (table)

Section titled “history (table)”

Every backup, restore, verify, config change, pause, prune. Who: viewer (read).

overview() — admin database

Section titled “overview() — admin database”

Who: viewer. One row per database on the server.

doctor()

Section titled “doctor()”

Who: viewer (runs as SECURITY DEFINER). Health checks: extension loaded, s3 settings, credentials file, database backups (age vs schedule), restore tests, workers, archive_mode (info only) and replication_slots.

rowless_tables()

Section titled “rowless_tables()”

Who: viewer. Tables whose rows the next backup skips.

to_cron(schedule text) RETURNS text

Section titled “to_cron(schedule text) RETURNS text”

Who: viewer. Shows how a schedule text is read: SELECT pgbx.to_cron('every 6 hours');

Policy (admin)

Section titled “Policy (admin)”

configure(...)

Section titled “configure(...)”

Who: pgbx_admin. Only the arguments you pass change. Made for migrations.

set_schedule(schedule text) RETURNS text

Section titled “set_schedule(schedule text) RETURNS text”

Who: admin. 'every 15 minutes', 'every 1 hour', 'hourly', 'daily', 'daily at 02:30', 'weekly', 'weekly on sunday at 03:00', or cron '0 */6 * * *'.

set_retention(max_backups int DEFAULT NULL, max_days int DEFAULT NULL) RETURNS text

Section titled “set_retention(max_backups int DEFAULT NULL, max_days int DEFAULT NULL) RETURNS text”

Who: admin. Whichever deletes first; newest always kept; max_days ≤ pgbx.max_days_limit.

pause(reason text DEFAULT NULL) RETURNS text / resume() RETURNS text

Section titled “pause(reason text DEFAULT NULL) RETURNS text / resume() RETURNS text”

Who: admin. Stops/starts automatic backups. Manual backups still work.

set_data_scope(include text[] DEFAULT NULL, exclude text[] DEFAULT NULL) RETURNS text

Section titled “set_data_scope(include text[] DEFAULT NULL, exclude text[] DEFAULT NULL) RETURNS text”

Who: admin. No arguments = every row. See Data scope.

set_verify_schedule(schedule text) RETURNS text

Section titled “set_verify_schedule(schedule text) RETURNS text”

Who: admin. Default 'weekly on sunday at 04:00'; 'never' or 'off' disables.

Jobs (admin)

Section titled “Jobs (admin)”

backup_now() RETURNS bigint

Section titled “backup_now() RETURNS bigint”

Queues a backup. Returns the history id.

restore(into_db text, at timestamptz DEFAULT now()) RETURNS bigint

Section titled “restore(into_db text, at timestamptz DEFAULT now()) RETURNS bigint”

Restores the newest backup at or before at into a new database. Live database untouched.

verify_now() RETURNS bigint

Section titled “verify_now() RETURNS bigint”

Restores the newest backup into a scratch database, checks it, drops it.

download_url(backup_id bigint DEFAULT NULL, expires interval DEFAULT '1 hour') RETURNS text

Section titled “download_url(backup_id bigint DEFAULT NULL, expires interval DEFAULT '1 hour') RETURNS text”

Presigned S3 link to one backup (newest when backup_id is NULL). expires between 1 minute and 7 days. Revoked from PUBLIC; granted to admin.
